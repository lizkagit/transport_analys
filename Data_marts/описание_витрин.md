# Описание выходных витрин данных (Marts) для DataLens

В данном документе представлено описание структуры и состава аналитических таблиц (витрин), формируемых в рамках предобработки данных о ДТП за 2022–2024 годы.

---

## 1. mart_dtp_overview (Обзорный реестр ДТП)

**Назначение:** Базовая детальная витрина уровня отдельных происшествий. Служит основным источником для построения общих графиков, KPI-карточек и фильтрации по административным единицам.

| Название поля | Тип данных | Описание | Тип фактора |
| :--- | :--- | :--- | :--- |
| `dtp_id` | String / Int | Уникальный идентификатор дорожно-транспортного происшествия | Идентификатор |
| `moment_date` | Date | Дата происшествия | Временной контекст |
| `year` | Int | Год происшествия (2022–2024) | Временной контекст |
| `month` | Int | Месяц происшествия (1–12) | Временной контекст |
| `day_of_week` | Int | День недели (0 = Понедельник, 6 = Воскресенье) | Временной контекст |
| `hour` | Int | Час происшествия (0–23) | Временной контекст |
| `time_of_day` | String | Укрупнённое время суток (Утро / День / Вечер / Ночь) | Производный |
| `season` | String | Сезон (Зима / Весна / Лето / Осень) | Производный |
| `is_weekend` | Boolean | Флаг выходного дня (Суббота, Воскресенье) | Производный |
| `is_night` | Boolean | Флаг ночного времени (с 22:00 до 06:00) | Производный |
| `is_rush_hour` | Boolean | Флаг часа пик (7:00–10:00 и 17:00–20:00) | Производный |
| `type_code` | Int | Исходный код типа ДТП из справочника | Прямой |
| `type_name_decoded`| String | Расшифрованное название типа ДТП (напр., «Наезд на пешехода») | Производный |
| `type_group` | String | Укрупнённая аналитическая группа (6 основных групп + прочее) | Производный |
| `severity` | String | Тяжесть последствий («Гибель» или «Ранение») | Производный |
| `dead_count` | Int | Количество погибших | Прямой |
| `injured_count` | Int | Количество раненых | Прямой |
| `dead_children_count`| Int | Количество погибших детей | Прямой |
| `injured_children_count`| Int| Количество раненых детей | Прямой |
| `vehicles_count` | Int | Количество транспортных средств, участвовавших в ДТП | Прямой |
| `participant_count`| Int | Общее количество участников происшествия | Производный |
| `area_id` | Int | Идентификатор региона / области | Прямой |
| `district_id` | Int | Идентификатор административного района | Прямой |
| `source_year` | Int | Год из источника данных | Прямой |

## 2. mart_time_dynamics (Агрегированная временная динамика)

**Назначение:** Агрегированная витрина для анализа трендов, сезонности и распределения показателей тяжести и причинности по временным срезам. Оптимизирована для быстрых дашбордов динамики.

| Название поля | Тип данных | Описание |
| :--- | :--- | :--- |
| `year` | Int | Год анализа |
| `month` | Int | Месяц анализа |
| `season` | String | Сезон |
| `day_of_week` | Int | День недели (0–6) |
| `time_of_day` | String | Укрупнённое время суток |
| `is_weekend` | Boolean | Флаг выходного дня |
| `dtp_count` | Int | Общее количество ДТП в данном временном срезе |
| `dead_total` | Int | Суммарное количество погибших |
| `injured_total` | Int | Суммарное количество раненых |
| `dead_children_total` | Int | Суммарное количество погибших детей |
| `injured_children_total`| Int | Суммарное количество раненых детей |
| `pct_speed_viol` | Float | Доля ДТП с нарушениями скоростного режима (0.0 – 1.0) |
| `pct_priority_viol` | Float | Доля ДТП с нарушениями приоритета / проезда светофора |
| `pct_bad_road` | Float | Доля ДТП, произошедших в условиях дефектов дорожного покрытия / среды |
| `pct_pedestrian` | Float | Доля ДТП с пешеходным конфликтом |
| `pct_night` | Float | Доля происшествий в ночное время |
| `pct_severity_fatal` | Float | Доля ДТП с летальным исходом (показатель летальности среза) |

---

## 3. mart_factor_profile (Профиль факторов риска)

**Назначение:** Специализированная витрина для исследования взаимосвязи между внешними/внутренними факторами и тяжестью последствий. Все булевы флаги переведены в текстовый формат ("Да" / "Нет") для удобной фильтрации через селекторы DataLens.

| Название поля | Тип данных | Описание (Значения: "Да" / "Нет") |
| :--- | :--- | :--- |
| `dtp_id` | String / Int | Идентификатор происшествия |
| `year` | Int | Год происшествия |
| `type_group` | String | Укрупнённая группа типа ДТП |
| `severity` | String | Тяжесть последствий («Гибель» / «Ранение») |
| `has_speed_violation` | String | Было ли зафиксировано нарушение скоростного режима |
| `has_priority_violation`| String | Было ли зафиксировано нарушение очередности или сигналов светофора |
| `has_alcohol_violation` | String | Присутствовал ли фактор алкогольного/наркотического опьянения |
| `has_pedestrian_conflict`| String | Участвовал ли в ДТП пешеход |
| `has_bad_road_condition`| String | Зафиксированы ли сопутствующие недостатки дорожной сети |
| `has_young_driver` | String | Был ли среди водителей участник в возрасте до 25 лет |
| `has_novice_driver` | String | Был ли среди водителей участник со стажем вождения менее 2 лет |
| `has_truck` | String | Участвовал ли в происшествии грузовой транспорт |
| `has_bus` | String | Участвовал ли в происшествии автобус / микроавтобус |
| `has_taxi` | String | Участвовал ли в происшествии автомобиль такси |
| `has_motorcycle` | String | Участвовал ли в происшествии мотоцикл / мопед |
| `is_night` | String | Произошло ли ДТП ночью |
| `is_weekend` | String | Произошло ли ДТП в выходной день |
| `is_rush_hour` | String | Произошло ли ДТП в час пик |
| `time_of_day` | String | Время суток (текст) |
| `season` | String | Сезон года (текст) |
| `dead_count` | Int | Число погибших в конкретном ДТП |
| `injured_count` | Int | Число раненых в конкретном ДТП |
| `participant_count` | Int | Общее число участников в конкретном ДТП |

## 4. mart_spatial_risk (Пространственные факторы и плотность риска)

**Назначение:** Геоаналитическая витрина, агрегированная по пространственным индексам (H3-ячейкам `cell_id`) и годам. Позволяет строить тепловые карты (Choropleth/Polygon слои) в DataLens и выявлять очаги аварийности.

| Название поля | Тип данных | Описание |
| :--- | :--- | :--- |
| `cell_id` | String | Идентификатор дискретной пространственной ячейки (H3) |
| `year` | Int | Год агрегации |
| `dtp_count` | Int | Количество ДТП, попавших в ячейку за год |
| `dead_total` | Int | Всего погибших в ячейке |
| `injured_total` | Int | Всего раненых в ячейке |
| `dead_children_total` | Int | Всего погибших детей в ячейке |
| `pct_fatal` | Float | Доля ДТП со смертельным исходом в ячейке |
| `pct_injured` | Float | Доля ДТП с ранеными в ячейке |
| `pct_speed_viol` | Float | Доля ДТП, связанных со скоростью |
| `pct_priority_viol` | Float | Доля ДТП с нарушением приоритета |
| `pct_pedestrian` | Float | Доля ДТП с пешеходами |
| `pct_bad_road` | Float | Доля ДТП с дефектами дороги |
| `pct_night` | Float | Доля ДТП в ночное время |
| `pct_weekend` | Float | Доля ДТП в выходные дни |
| `pct_rush_hour` | Float | Доля ДТП в часы пик |
| `pct_at_intersection` | Float | Доля ДТП на перекрестках |
| `pct_on_open_road` | Float | Доля ДТП на открытых участках дорог (перегонах) |
| `pct_has_camera` | Float | Доля ДТП в зоне действия комплексов фотовидеофиксации |
| `pct_has_crosswalk_pt` | Float | Доля ДТП в зоне пешеходных переходов |
| `pct_has_traffic_light`| Float | Доля ДТП на регулируемых участках |
| `pct_has_bus_stop` | Float | Доля ДТП вблизи остановок общественного транспорта |
| `avg_lane_width_m` | Float | Средняя ширина полосы движения в местах ДТП |
| `avg_dist_intersection`| Float | Среднее расстояние до ближайшего перекрестка |
| `avg_dist_crosswalk` | Float | Среднее расстояние до пешеходного перехода |
| `avg_dist_bus_stop` | Float | Среднее расстояние до ближайшей остановки |
| `avg_poi_100m` | Float | Среднее количество точек притяжения (POI) в радиусе 100м |
| `avg_poi_300m` | Float | Среднее количество точек притяжения (POI) в радиусе 300м |
| `mortality_rate` | Float | Коэффициент смертности в ячейке (`dead_total / dtp_count`) |
| `cell_h3_res` | Int | Разрешение H3-индекса ячейки |
| `cell_has_traffic_light`| Boolean | Инфраструктурный признак: наличие светофора в границах ячейки |
| `cell_has_crosswalk` | Boolean | Наличие пешеходного перехода в границах ячейки |
| `cell_has_bus_stop` | Boolean | Наличие остановки ОТ в границах ячейки |
| `cell_is_intersection` | Boolean | Является ли топология дорог в ячейке перекрестком |
| `cell_is_open_road` | Boolean | Преобладает ли открытый перегон |
| `cell_has_camera` | Boolean | Стационарная камера в ячейке |
| `cell_traffic_lane_amount`| Float| Базовое/среднее число полос движения в ячейке |
| `cell_lane_width_m` | Float | Базовая ширина полосы в ячейке |
| `cell_is_multilane` | Boolean | Флаг многополосности дороги в ячейке |
| `cell_road_class` | String | Классификация дороги (напр., `footway`, `primary`) |
| `cell_landuse_type` | String | Категория использования земель (напр., `residential`) |

## 5. mart_weather_context (Погодный контекст) — [ЗАГЛУШКА]

**Назначение:** Перспективная витрина (блок Исполнителя 3) для оценки влияния факторов видимости, осадков, гололедных явлений и световой среды.

| Название поля | Тип данных | Описание / Расчетный показатель |
| :--- | :--- | :--- |
| `year` | Int | Год агрегации |
| `month` | Int | Месяц агрегации |
| `season` | String | Сезон года |
| `cell_id` | String | Пространственная привязка (опционально) |
| `dtp_count` | Int | Число ДТП в данных метеоусловиях |
| `dead_total` | Int | Суммарное число погибших |
| `injured_total` | Int | Суммарное число раненых |
| `pct_ice_risk` | Float | Доля ДТП в условиях риска гололеда |
| `pct_low_visibility` | Float | Доля ДТП в условиях ограниченной видимости |
| `pct_bad_weather` | Float | Доля ДТП при сильных осадках |
| `pct_dark_no_lights` | Float | Доля ДТП в темное время без освещения |
| `avg_temp_c` | Float | Средняя температура воздуха |
